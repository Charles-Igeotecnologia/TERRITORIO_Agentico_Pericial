# 03 — Reconstituição Cartográfica

Área destinada aos produtos intermediários e finais de reconstituição vetorial e georreferenciamento documental.

Subcategorias previstas:
- `vetores/`;
- `georreferenciamento/`;
- `controles/`.

Cada reconstituição deve registrar método, controles, CRS, resíduos, tolerâncias e limitações.
