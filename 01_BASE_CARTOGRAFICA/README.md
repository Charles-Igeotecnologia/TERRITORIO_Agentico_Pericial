# 01 — Base Cartográfica

Área destinada às bases de referência territorial utilizadas nas análises periciais.

Subcategorias previstas:
- `referencia/`: camadas oficiais e cartografia de apoio;
- `limites/`: limites administrativos, cadastrais ou territoriais;
- `imagens/`: ortofotos, imagens de satélite e demais matrizes georreferenciadas.

Todo dado incorporado deve possuir metadados mínimos e identificação do CRS.
